  Root Cause Identified

  RISKS.md uses this format:
  - **Probability**: Medium
  - **Impact**: High

  Parser looks for:
  r'(?:severity|priority|level|overall):\s*(critical|high|medium|low)'

  Result: Parser cannot find "severity" field because RISKS.md uses "Probability" and "Impact"
  instead!

  So:
  - severity_match returns None
  - Default fallback: severity = 'medium' (line 2098)
  - ALL risks are classified as "medium"
  - critical_risks list is empty
  - Only the generic "Best Practices" section appears

  ---
  VERDICT: THIS IS A SCRIPT ISSUE

  Type: Parser mismatch between expected format and actual RISKS.md format

  Impact: The script fails to extract severity correctly, so:
  1. No risks are classified as "critical" or "high"
  2. The "Critical Risk Areas" and "High Risk Areas" sections don't appear
  3. Only generic mitigation strategies are shown

  ---
  THE FIX

  Option 1: Update Parser to Handle Probability+Impact (Better)

  # In _parse_risks() around line 2092-2098
  severity_match = re.search(
      r'(?:severity|priority|level|overall):\s*(critical|high|medium|low)',
      risk_content,
      re.IGNORECASE
  )

  if not severity_match:
      # Fallback: derive severity from Probability + Impact
      prob_match = re.search(r'Probability:\s*(High|Medium|Low)', risk_content, re.IGNORECASE)
      impact_match = re.search(r'Impact:\s*(High|Medium|Low)', risk_content, re.IGNORECASE)

      if prob_match and impact_match:
          prob = prob_match.group(1).lower()
          impact = impact_match.group(1).lower()

          # Risk matrix: Prob x Impact
          if impact == 'high' and prob in ['high', 'medium']:
              severity = 'critical'
          elif impact == 'high' or prob == 'high':
              severity = 'high'
          else:
              severity = 'medium'
      else:
          severity = 'medium'
  else:
      severity = severity_match.group(1).lower()

  Option 2: Update _build_pitfalls_section to Show Risk Descriptions (Also needed)

  Even if we fix severity detection, the current output format is still wrong. It should show:

  - **Risk 005: Data Persistence Limitations** - Browser localStorage may be unavailable
